# References

`MLDS_Feature_Selection.pdf` is the project spec. It is the only file kept in
git.

The papers below are kept locally, not in git. The repo is public, and their
licenses do not allow redistribution. Download them into this folder under the
file names given.

| File | Paper | Source |
|------|-------|--------|
| `Donoho_Jin_2004_Higher_Criticism.pdf` | Donoho, D. and Jin, J. (2004). Higher criticism for detecting sparse heterogeneous mixtures. *Annals of Statistics* 32(3), 962-994. | https://arxiv.org/abs/math/0410072 |
| `Donoho_Jin_2008_HC_Thresholding_Phase_Diagram.pdf` | Donoho, D. and Jin, J. (2008). Feature selection by Higher Criticism thresholding: optimal phase diagram. | https://arxiv.org/abs/0812.2263 |

The 2004 paper defines the Higher Criticism statistic, for detection. The 2008
paper defines Higher Criticism thresholding, for feature selection
(Definitions 1.2 and 1.3).
